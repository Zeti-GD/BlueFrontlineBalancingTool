# Blue Frontline Balancing Tool

> **블루 아카이브 팬게임 *MolluFPS* 교전 밸런스 분석 & 1v1 TTK 시뮬레이터**

---

## 🌟 주요 기능

1. **언리얼 엔진 프로젝트 직접 연동**
   - 언리얼 엔진 프로젝트에서 캐릭터 스탯(체력, 실드, RPM, 총기 대미지, 사거리 등)을 자동으로 불러와 동기화합니다.

2. **다양한 기획 데이터 불러오기**
   - 구글 스프레드시트 링크 연동
   - 엑셀(`.xlsx`, `.xls`), CSV 파일 지원

3. **1v1 맞대결 & TTK 시뮬레이션**
   - 선택된 캐릭터 간 맞대결 승패 예측 및 실시간 TTK 비교
   - 순수 평타, 스킬 콤보, 풀 콤보 4단계 TTK 지원
   - 교전 거리 및 헤드샷율 실시간 반영

4. **샷건 팰릿 계산 & 듀얼 무기 지원**
   - 산탄총 팰릿(산탄 발사체) 개수 및 집탄율 거리 감쇄 반영
   - 무기를 2개 보유한 캐릭터의 무기 전환 및 개별 스탯 조절

5. **데이터 내보내기**
   - 수정한 밸런스 데이터를 엑셀(`.xlsx`) 또는 JSON 파일로 저장

---

## 🚀 실행 및 빌드 방법

### 1. 프로그램 바로 실행
- 루트 폴더의 **`Run_App.bat`**을 더블클릭하면 프로그램이 바로 실행됩니다.
- 또는 **`BlueFrontlineBalancingTool.exe`**를 직접 더블클릭해도 즉시 실행됩니다.

### 2. EXE 파일 생성 (빌드)
- 루트 폴더의 **`Build_EXE.bat`**을 더블클릭하면 최신 소스코드를 바탕으로 단독 실행 파일(`BlueFrontlineBalancingTool.exe`)이 자동 생성됩니다.
