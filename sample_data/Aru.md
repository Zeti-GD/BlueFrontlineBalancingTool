# 3. 스킬 정보

## A. 패시브 스킬: 아무도 못 봤겠지?

### ⅰ. 스킬 개요

- 상황에 따라 자동으로 몸을 수습하는 능력을 발휘하는 패시브다.
- 아루가 자신의 감전 폭탄이나 하드보일드 샷에 휘말리는 실수를 했을 때, 이를 아무 일도 없던 것처럼 넘기며 전투 흐름을 이어간다.
- 효과 상세
    
    
    | 트리거 조건 | 발동 효과 |
    | --- | --- |
    | 아루가 자신의 하드보일드 샷 폭발탄에 피해를 입었을 때 | 자신이 받는 폭발 피해가 50% 감소 |
    | 아루가 자신의 감전 폭탄에 감전되었을 때 |   • 감전 시간 50% 감소
      • 감전 후 아루의 이동 속도 +20% (2초간) |

### ⅱ. 스킬 규칙

1. 발동 조건 및 효과
- 조건부 + 강화형 스킬이다.
    - 참고: [스킬 시스템 기획서](https://www.notion.so/230377f7f6df80a4a3dbf49e0c245192?pvs=21)
- 트리거는 아루 본인의 스킬로 인한 자해 상황으로 한정된다.
- 아래 두 가지 상황 중 하나가 발생할 경우 조건이 충족된다.
    1. 감전 폭탄에 감전되었을 경우
    2. 하드보일드 샷 폭발에 본인이 피해를 입었을 경우
- 아루가 자신의 하드보일드 샷 폭발탄에 피해를 입었을 때 효과
    - 하드보일드 샷 폭발 피해 50% 감소
- 아루가 자신의 감전 폭탄에 감전되었을 때
    - 감전 시간 50% 감소
    - 감전 후 2초 간 아루의 이동 속도 + 20% (1초 후 서서히 기본 이동 속도로 전환)
- 각 조건에 따라 서로 다른 효과가 발동되며, 내부 쿨타임이 존재하여 중복 발동은 제한된다.
    - 쿨타임: 20초 (둘 중 하나가 발동 될 시 쿨타임 돈다.)

## B. 액티브 스킬 1: 하드보일드 샷 (Hardboiled Shot)

### ⅰ. 스킬 개요

- 아루가 장전된 탄환을 고위력의 폭발탄 3발로 전환하여 사격을 준비한다.
- 폭발탄은 충돌 지점에 고정되어 지연 폭발하며, 범위 피해를 입힌다.
- 강력한 화력 대신, 탄약 소진 전까지는 기본 공격이 봉인되고 자신도 피해를 입을 수 있는 고위험 고보상 스타일의 스킬이다.

### ⅱ. 스킬 규칙

- 스킬은 단일형 스킬 + 장착형 스킬이다.
    - 참고: [스킬 시스템 기획서](https://www.notion.so/230377f7f6df80a4a3dbf49e0c245192?pvs=21)
    - 스킬 쿨타임은 기본 스킬 시스템의 장착형 스킬을 따라간다.
- 스킬 사용 시, 장전된 탄환이 폭발탄 3발로 일괄 교체된다.
    - 폭발탄을 다 쓰고 다시 탄환으로 복귀할 때 장전된 탄환은 모두 자동으로 충전된다.
    - 예시) 2/5발 → 폭발탄 변경 → 폭발탄 모두 소모 → 5/5발
- 폭발탄은 직선 궤도로 날라가며 적 또는 지형과 충돌 시 해당 위치에 고정된다.
- 고정 후 1.5초 뒤 폭발하며 범위 내 적, 파괴 가능한 오브젝트 피해를 준다.
    - 아군에게는 피해를 입히지 않습니다.
    - 아루 본인에게는 피해를 줍니다.
        
        ![image.png](attachment:56229d21-6d5e-43ae-be36-48e585235367:image.png)
        
- 폭발탄을 모두 소진하기 전까지는 기본 공격을 할 수 없게 된다.
    - 이 점은 강력한 폭발탄 스킬의 디메리트다.
- 기본 전용 무기의 공격처럼 에임 조준이 가능하다.
- 폭발탄은 발사 후 어떤 형태로든 취소가 불가능하다.
- 요약
    
    
    | 단계 | 설명 |
    | --- | --- |
    | 발사 | 직선 궤도로 날아감 |
    | 충돌 | 지형, 적, 오브젝트와 충돌 시 해당 위치에 고정 |
    | 폭발 | 고정 후 1.5초 뒤 폭발 (범위 피해 발생) |
    | 반응 대상 | 적 / 파괴 가능한 오브젝트 / 본인 (피해), 아군 (무효) |
    

### ⅲ. 스킬 스탯

- 임의의 스킬 스탯이며 게임 플레이를 하면서 밸런스 수치가 조절 가능하다.
    - 단, 탄환 수, 폭발 지연 시간은 고정한다.
    - 폭발 반경, 스킬 장착 속도, 폭발탄 재장전 시간, 쿨타임 등이 수치 조절 대상이다.

## C. 액티브 스킬 2: 퇴각은 미학이야

### ⅰ. 스킬 개요

- 아루가 감전 폭탄을 던지며 뒤로 일정 거리를 점프하여 근접 위협을 회피한다.
    - 애니메이션 문제가 있다면 기절로 대체 가능하다.
    - 감전 폭탄은 가운데 에임을 기준으로 직선으로 투척한다.
    
    ![image.png](attachment:ad601294-9004-4d44-96c6-896528afcfe2:image.png)
    
- 위치 조절을 실패할 경우 아루 본인도 감전(기절)에 걸리는 허당성 리스크를 포함한다.
    - 폭탄은 캐릭터나 지형, 벽에 튕겨 반사될 수 있다.
    - 반사될 때 줄어드는 속도를 반발계수라고 하며 줄어드는 속도는 50% 줄어든다.
        
        ![image.png](attachment:18e08472-d91c-47e8-acf4-895be1556651:image.png)
        

### ⅱ. 스킬 규칙

- 스킬은 단일형 + 즉시 발동형 중 키다운 방식이다.
    - 참고: [스킬 시스템 기획서](https://www.notion.so/230377f7f6df80a4a3dbf49e0c245192?pvs=21)
- 폭탄은 튕길 수 있으며 던지고(손을 떠나자마자) 1.2초 후 후 터지며 범위 내 적을 확정으로 감전(기절) 상태로 만든다.
    - 2초 동안 상태이상 상태로 만든다.
    - 아루 본인도 범위에 있으면 감전되며, 아군은 감전되지 않는다.
- 스킬 사용 시, 아루는 감전 폭탄을 손에 든 후  에임에 맞춰 바로 직선으로 던지고, 동시에 뒤로 점프한다.
    - 점프할 때 0.2초 간 무적 판정이다.
    - 폭탄도 직선 형태로 날아간다.
- 스킬은 지상에서만 발동 가능하다. (공중 상태에서 사용 불가)
