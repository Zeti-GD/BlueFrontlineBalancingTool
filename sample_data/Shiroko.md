\## B. 액티브 스킬 1: 드론 전개



\### ⅰ. 스킬 사용



\- 스킬 사용 시 드론이 시로코 캐릭터의 후방에 소환된다. (소환형 스킬)

&nbsp;   - 시야 기준이 아닌 캐릭터 기준 후방에 소환된다.

&nbsp;       

&nbsp;       !\[image.png](attachment:132797e7-dfd2-429f-9529-733105558b26:image.png)

&nbsp;       

\- 만약 소환될 위치에 벽, 구조물 등의 콜라이더가 있다면 소환되지 않는다.

&nbsp;   - 드론 소환이 불가능한 상황이면, 스킬 사용이 불가능해진다.

&nbsp;       

&nbsp;       !\[image.png](attachment:90090f5a-a510-4f79-a562-24baa96c4df4:image.png)

&nbsp;       

\- 플레이어는 드론 소환 중에 이동 외의 행동이 불가능하다.

&nbsp;   - 드론 소환 시 전용 휴대 전화를 조작하는 전용 소환 모션을 발동하기 때문이다.

&nbsp;   

&nbsp;   !\[image.png](attachment:0fe5af76-bb70-4a50-aec1-976bb0bf26de:image.png)

&nbsp;   

\- 소환된 드론은 자동으로 시로코 캐릭터의 머리 위로 날아오른다.

&nbsp;   - 위로 날아오르는 행동까지 완료해야 드론의 소환 과정이 모두 완료된다.

&nbsp;       

&nbsp;       !\[image.png](attachment:666413c3-6fd4-445c-b6c8-3008705ad791:image.png)

&nbsp;

\### ⅵ. 드론 미사일 매커니즘



\- 드론 미사일은 드론의 에임 방향을 따라 일직선으로 날아간다.

&nbsp;   - 날아가는 동안 중력, 공기 저항의 영향을 받지 않는다.

&nbsp;       

&nbsp;       !\[image.png](attachment:c4d1eb13-661c-453c-a9c5-866b58a12389:image.png)

&nbsp;       

\- 미사일은 콜라이더와 접촉하거나 최대 사거리에 도달하면 즉시 폭발한다.

&nbsp;   - 최대 사거리에 도달한 경우, 콜라이더와 접촉하지 않아도 폭발한다.

&nbsp;       

&nbsp;       !\[image.png](attachment:e1e0c3b9-80d9-46c7-a7ee-5b4319dbb23b:image.png)

&nbsp;       

\- 유도 대상이 존재하는 경우, 미사일이 해당 적을 향해 유도된다.

&nbsp;   - 이동 방향이 유도 대상을 향해 실시간으로 변경되는 매커니즘

&nbsp;       

&nbsp;       !\[image.png](attachment:40d6313a-b5be-424f-bea1-bfb5dddd201c:image.png)

&nbsp;       

\- 유도 대상과의 사이에 물체가 있어도, 미사일은 유도 대상을 향해 직선으로 날아간다.

&nbsp;   - 유도 대상을 향해 날아가다 물체에 부딪히거나 최대 사거리에 도달하면 폭발한다.

&nbsp;       

&nbsp;       !\[image.png](attachment:a83505d6-8a58-45ac-aa4b-e6b8a0198968:image.png)

\## C. 액티브 스킬 2: 전방 수류탄



\### ⅰ. 스킬 요약



\- 스킬 사용 시 수류탄을 손에 장착한다. (장착형 스킬)

\- 이후 스킬을 사용하려면 마우스의 좌클릭 또는 우클릭을 해야한다.

&nbsp;   - 좌클릭 또는 우클릭을 하면 수류탄을 던진다.

\- 수류탄은 최대 3개 보유할 수 있다.

&nbsp;   - 수류탄 사용시 수류탄이 1개씩 줄어들고 쿨타임이 지나면 1개씩 다시 충전된다. (스택형 스킬)
