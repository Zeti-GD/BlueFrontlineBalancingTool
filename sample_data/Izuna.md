\## A. 패시브 스킬: 이즈나 인법첩



\### ⅰ. 스킬 개요



\- 이즈나는 전면 벽에 접촉한 상태에서 점프 입력을 유지하면 일정 시간 동안 벽을 수직으로 등반할 수 있다.

\- 벽타기는 고지 점령, 진입 루트 확장, 탈출 루트 확보 등 전략적 이동 선택지를 제공한다.

\- 지속시간 종료, 입력 해제, 벽의 끝 도달 시 자동 종료된다.

\- 착지 후에만 재사용이 가능하며, 공중 상태에서는 재사용할 수 없다.

\- 벽타기 종료 직후 약 0.25초 동안 상승 모멘텀이 유지되어 클라이밍 점프가 가능하다.

\- E 스킬 「이즈나 인법첩」과 연계하여 고지 접근 또는 탈출 루트 설계가 가능하다.



\### ⅱ. 스킬 규칙



\- 스킬은 \*\*조건부 효과 발동형 패시브 스킬\*\*이다.

&nbsp;   - 별도의 쿨타임은 존재하지 않는다.

&nbsp;   - 재사용 조건은 “보행 가능 지형에 착지”이다.

\- 전면 벽과 충돌한 상태에서 점프 입력 유지 시 발동된다.

&nbsp;   - 등 방향 벽에는 탑승할 수 없다.

&nbsp;   - 입력 해제 시 즉시 종료된다.

\- 벽이 끝날 경우 즉시 종료된다.

\- 공중 상태에서 재입력은 무효 처리된다.

\- 너무 얇거나 비정형 물체에는 탑승할 수 없다.

\- Collision 판정 기준:

&nbsp;   - Untagged Wall → 탑승 가능

&nbsp;   - Trigger / Barrier → 탑승 불가

\- 벽타기 도중 CC 피격 시 즉시 중단된다.

&nbsp;   - 넉백은 무시하고 유지된다.

&nbsp;   - 일반 데미지는 이동에 영향 없음.

\- 이동 중 스킬 사용은 불가하다.

&nbsp;   - 화면 회전 외 모든 입력 봉인

&nbsp;   - 조준 상태 자동 해제

\- 벽/장애물 강제 충돌 시 즉시 종료된다.

\## B. 액티브 스킬 1: 비기! 다용도 수리검



\### ⅰ. 스킬 개요



\- 이즈나의 난이도 높은 기본 총기를 보조하는 전술형 제어 스킬이다.

\- Q 입력 후 좌/우 클릭에 따라 서로 다른 효과의 수리검을 투척한다.

\- 착탄 지점을 기준으로 범위 효과가 발생한다.

\- 수리검은 캐릭터와 충돌하지 않으며 지형 및 오브젝트에 충돌할 때 폭발한다.

\- 방패, 고체력, 고속 돌진형 적 등 상대하기 까다로운 대상을 제어하기 위한 대응 수단이다.



\### ⅱ. 스킬 사용 방법 (Input Flow)



\*\*a. 기본 사용 흐름\*\*



\- Q 키 입력 시 수리검 선택 상태에 진입한다.

\- 선택 상태에서는 수리검을 아직 발사하지 않은 대기 상태가 된다.

\- 선택 상태에서

&nbsp;   - 좌클릭 → 실명 수리검 투척

&nbsp;   - 우클릭 → 연기 수리검 투척

\- 선택 입력 시 즉시 발사되며 스킬 쿨타임이 적용된다.



\*\*b. 선택 상태 유지 규칙\*\*



\- 선택 상태에서는 이동 및 시점 조작이 가능하다.

\- 선택 상태는 최대 2초 동안 유지된다.

\- 다음 조건 중 하나가 발생하면 선택 상태가 종료된다.

&nbsp;   

&nbsp;   1. 좌클릭 또는 우클릭 입력 (스킬 발사)

&nbsp;   

&nbsp;   2. 2초 동안 추가 입력 없음

&nbsp;   

&nbsp;   3. Q 키 재입력

&nbsp;   



\*\*c. 선택 취소 규칙\*\*



\- 다음 상황에서 스킬이 취소된다.

&nbsp;   - 선택 상태에서 2초 동안 입력 없음

&nbsp;   - 선택 상태에서 Q 키 재입력

&nbsp;   - 선택 상태 중 군중제어(CC) 피격

\- 취소 시 다음 규칙이 적용된다.

&nbsp;   - 스킬은 발사되지 않는다.

&nbsp;   - 0.5초 동안 재사용할 수 없다.

&nbsp;   - 쿨타임은 발생하지 않는다.

\### ⅲ. 수리검 투사체 충돌 규칙



\*\*a. 캐릭터 충돌\*\*



\- 수리검은 캐릭터와 충돌하지 않는다.

\- 캐릭터에 닿아도 충돌 판정 없이 그대로 통과한다.

\- 캐릭터 충돌로 인해

&nbsp;   - 투사체 경로가 변경되지 않는다.

&nbsp;   - 폭발이 발생하지 않는다.



\*\*b. 지형 및 오브젝트 충돌\*\*



수리검이 다음 대상에 충돌할 경우 즉시 폭발한다.



\- 지형 (벽, 바닥, 천장)

\- 고정 오브젝트

\- 환경 구조물

\- 방패류 오브젝트



충돌 시 해당 지점을 기준으로 스킬 효과가 발동된다.



\*\*c. 최대 사거리 폭발\*\*



수리검은 최대 이동 거리에 도달할 경우 자동으로 사라진다.



\### ⅳ. 좌클릭: 실명 수리검



\*\*a. 기능 목적\*\*



\- 단일 타겟 저지력 강화

\- 돌진 / 이동 속도 기반 캐릭터 대응

\- 교전 중 생존율 급락 유도용 제압 기술



\*\*b. 발동 규칙\*\*



\- 수리검이 지형 또는 오브젝트에 충돌하면 섬광이 발생한다.

\- 반경 10m 내의 적과 본인에게 \*\*《실명 효과》\*\*를 적용한다.



\*\*《실명 효과》\*\*



\- 화면이 백색으로 변하며 시야가 차단된다.

\- 실명 종료 1초 전부터

&nbsp;   - 0.1초 간격으로 시야가 점진적으로 회복된다.

\- 섬광 발생 지점을 직접 바라보고 있는 대상에게만 판정된다.

\- 벽·지형·엄폐물 등에 의해 시야가 차단된 경우 효과가 적용되지 않는다.



\*\*「거리 기반 실명 시간」\*\*



섬광 발생 지점과의 거리에 따라 기본 실명 시간이 달라진다.



| 거리 | 기본 실명 시간 |

| --- | --- |

| 피격자 ≤ 4m | 4초 |

| 4m < 피격자 ≤ 7m | 2.5초 |

| 7m < 피격자 ≤ 10m | 1초 |



\*\*「시야각 보정」\*\*



| 시야각 | 적용 계수 |

| --- | --- |

| 정면 (0° ~ 60°) | 1.0 |

| 측면 (60° ~ 120°) | 0.7 |

| 후면 (120° ~ 180°) | 0.4 |



\*\*<계산식>\*\*



\- \*\*최종 실명 시간 = 거리 기반 실명 시간 × 시야각 보정값\*\*

&nbsp;   

&nbsp;   예시

&nbsp;   

&nbsp;   - 거리 3m / 정면 응시 → 4초 × 1.0 = 4초

&nbsp;   - 거리 3m / 측면 응시 → 4초 × 0.7 = 2.8초

&nbsp;   - 거리 8m / 후면 응시 → 1초 × 0.4 = 0.4초



\### ⅴ. 우클릭: 연기 수리검



\*\*a. 기능 목적\*\*



\- 공간 점유를 위한 시야 차단

\- 연막 내부 적 정보 제공



\*\*b. 발동 규칙\*\*



\- 수리검이 지형 또는 오브젝트에 충돌하면 《연막》이 생성된다.

\- 《연막》은 반경 10m 범위에서 7초 동안 지속된다.



\*\*《연막》\*\*



\- 6.5초 동안 시야를 차단하는 【반응성 연막】이 유지된다.

\- 이후 0.1초 간격으로 점진적으로 【반응성 연막】이 사라진다.

\- 1초마다 적을 감지하여 연막 내부의 적 캐릭터 수를 표시한다.

\- 소환된 오브젝트 등은 표시하지 않는다.



!\[적의 수를 표현하는 방식](attachment:7a95f263-bcc8-43a8-a920-e7aa0cd153bb:image.png)



적의 수를 표현하는 방식



\*\*【반응성 연막】\*\*



\- 연막 내부에서 폭발 피해가 발생할 경우

\- 폭발 범위만큼 연막이 일시적으로 제거된다.



이때



\- 제거된 영역은 잠시 시야가 확보된다.

\- 일정 시간이 지나면 연막이 다시 채워진다.



즉 폭발 공격을 통해 연막 내부를 순간적으로 확인할 수 있다.

\## C. 액티브 스킬2: 인법첩 – 질풍 대쉬



\### ⅰ. 스킬 개요



\- 이즈나의 핵심 생존기이자 포지셔닝 재정립용 기동 스킬이다.

\- 벽타기와 차별화된 “즉시 위험 이탈” 성격의 순간 가속 대쉬 구조.

\- 위기에 처한 아군에게 빠르게 합류하거나, 교전 중 빠른 각 전환을 가능하게 한다.

\- 최대 2회 충전형 구조로, 공격적 진입과 안전한 이탈을 동시에 설계할 수 있다.

\- 공중에서도 사용 가능하다.



\### ⅱ. 스킬 기능



\- 사용 시 플레이어의 앞 방향으로 빠르게 돌진

\- 짧은 거리이지만 즉시 위치를 변경하는 고속 이동기

\- 연속 사용은 가능하되, 최소 딜레이가 존재한다.



\### ⅲ. 스킬 규칙



\- 스킬은 \*\*충전형 액티브 스킬\*\*이다.

\- 최대 2회 충전 가능

\- 공중 사용 가능

\- 사용 시:

&nbsp;   - 조준 상태 자동 해제

&nbsp;   - 수리검 모드 자동 해제

&nbsp;   - 화면 회전 외 모든 입력 봉인

\- 이동 중 CC 피격 시 즉시 중단

&nbsp;   - 충전은 소모 유지

\- 넉백은 무시

\- 일반 데미지는 이동에 영향 없음

\- 벽/장애물 충돌 시 즉시 종료

&nbsp;   - 잔여 이동 거리 소멸
